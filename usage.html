ブラウザ版の使い方

公開URLから起動できます。下記のWindows用起動操作はPython版向けです。画面の入力・解析・比較は共通です。入力と結果はこのブラウザに保存され、他の端末へは自動同期されません。大切なデータはJSON・ZIPでも保存してください。

ツール一覧へ戻る
INPUT → ANALYZE → COMPARE → SAVE

条件を入れ、
流れの変化を確かめる。

カゴメ解析ツールを実際に使うための操作説明です。最初は手計算できる練習例を読み込み、そのあと自分の入力へ置き換えて進めます。

解析ツールを開く式と考え方を読む

この本は単独で開いています。ツールは完成物フォルダの「カゴメ解析ツールを起動.bat」から起動します。下の練習用JSONは、この本だけでも書き出せます。

ツールを起動したブラウザから開いた場合は、「解析ツールを開く」で編集画面へ戻れます。

本書は外部の画像・フォント・ライブラリを読み込みません。計算の原理と定義の根拠は、別冊の原理解説書で確認できます。

01 / START

起動・終了と、版の選び方

  1. 配布ZIPを使う場合は、フォルダ全体を展開します。
  2. WindowsにPython 3.9以降が入っていることを確認します。Python本体は配布物に含みません。
  3. 完成物フォルダの「カゴメ解析ツールを起動.bat」をダブルクリックします。ツールフォルダのrun.batからも起動できます。
  4. 初回はインターネットに接続し、必要なライブラリの準備が終わるまで待ちます。準備後、ブラウザに解析画面が開きます。
  5. 画面右上の「解析の版」で特許版または交通版を選びます。

起動ファイルは、ツール内に専用の実行環境.venvを作ります。解析中は起動時のコンソールを開いたままにしてください。終了するときは入力を保存してから、コンソールでCtrl＋Cを押します。

版使いどころ例：m・V
特許版（基本解析）用途に依存しない輸送モデルとして、量と単位を決めて使う並列経路数・輸送流量
交通版同じモデルの量を道路交通の量として読む車線数・交通流量（台/h）
両版の計算は共通です。同じ数値・格子・計算設定なら同じ数値結果になります。版を切り替えても入力値は維持され、単位は自動換算されません。交通版で使う場合は、長さをkm、速度をkm/h、流量を台/hにそろえてください。

版を指定して起動するファイルはrun-patent.batとrun-traffic.batです。共通起動では前回の作業を復元する場合があります。

02 / FIRST ANALYSIS

まず練習例を一度計算する

1練習例を読む
2入力を保存
3現在の入力を解析
4右・左・標準差を確認
  1. 「解析の準備」の「解説書の練習例を読み込む ↗」を押します。編集中の入力がある場合は、先に保存してください。
  2. 「解析名」を、例えば「練習例・変更前」にします。
  3. 上部の「入力を保存」を押します。
  4. 「解析・変更前後の比較」で、規格化が「原資料：j=V/m」、回転の計算が「原資料形：jから計算」、臨界点が0.5になっていることを確認します。
  5. 「現在の入力を解析」を押し、処理が終わったら「解析結果」を確認します。大きく見る場合は「結果を別の画面で開く ↗」を押します。

03 / PREPARE

自分の条件を用意する

先に、どの素辺をどの経路・区間に対応させるかを決めます。画面の格子図は接続を示す模式図です。入力する長さLを変えても、地図のように図の形が伸縮するわけではありません。

観測流量がある場合

「入力方法」で「各素辺の観測流量を使う」を選択し、全素辺のVを入力します。入口のinflowは計算に使いません。測定したVをそのまま診断するため、節点での流入・流出が一致するとは限りません。

入口からの流れを試算する場合

「入口の流入量から計算」を選択し、入口ごとのinflowと分岐割合を入力します。各素辺のVは計算結果になるため、Vの直接編集は無効になります。配分調整もこの方法で使います。

新しい格子を作る

  1. 「格子サイズ N」を1〜10の整数で指定します。
  2. 通常は「周囲に余白」を有効にします。
  3. 「合成例から新しく作る」を押します。Nと余白は、この操作で適用されます。
  4. 作成された合成データを、自分の条件へ書き換えます。
N欄だけを変更しても、現在の格子は作り直されません。「合成例から新しく作る」を押してください。既存の編集内容は、新しい入力に置き換わります。

代表ケースから始める

代表ケース観察すること

ケースを選んで「この代表ケースを読み込む」を押します。すべて説明用の合成データです。表示される説明は読み込んだ例の説明であり、編集後の結果は解析して確かめます。

04 / INPUT

素辺・分岐割合・入口の入力

素辺を選んで入力する

格子上の矢印をクリックするか、「素辺を指定」から場所を選びます。右側の入力欄で値を変更します。同じ区間の行きと帰りは別の有向素辺です。「表で見る ↓」を押すと、対応する入力行へ移動できます。

項目入力する内容条件・注意
m並列経路数。交通では車線数正の値。等価本数として小数も可。格子の接続本数は変わらない
L素辺の長さ正の値。交通版はkm
v輸送速度入力する場合は正。交通版はkm/h。nからVへの換算や密度の設定では必要
V単位時間あたりの総流量観測モードでは全素辺に0以上の値。交通版は台/h
μ規格化量の臨界基準標準との比較に使用。θ=0.5の練習例では正の1000
T分布の幅標準との比較に使用する正の値。μと同じ単位

最初は練習例のように全項目を埋めて使ってください。単位が違う入力を混ぜると、そのまま計算しても比較の意味がそろいません。

素片内の量nと、流量Vを混同しない

交通で「区間内に20台いる」はn=20です。L=0.5 km、v=40 km/hなら、換算する流量はV=20×40÷0.5=1600台/hです。

  1. 「各素辺の観測流量を使う」を選びます。
  2. 対象素辺のL・vを入力します。
  3. 右側の「素片内の量 n から流量を換算」を開き、nを入力します。
  4. 「nから流量Vに換算」を押します。

これは一回の換算です。L・vを後から変えてもVは自動更新されません。nを固定した比較にしたい場合は、変更後に再換算します。

分岐割合と入口を入力する

「編集する表」を「分岐割合」に変えると、各節点へ入る向きごとにS（直進）、R（右）、L（左）を入力できます。各値は0以上で、各行のS＋R＋L＝1です。この表のLは左回りの割合で、素辺表のL（長さ）とは別です。

入口から計算する場合は、表を「入口の流入量」に変え、各入口のinflowへ0以上の流量を入力します。流さない入口は0にします。

検索・一括入力・取り消し

  • 「場所を検索」にC(2,2)や向き1を入力すると表を絞り込めます。
  • 「選択した節点のみ」で、選択場所に関係する行を表示できます。表はページ送りできます。
  • 「複数の行へ一括入力」で項目と値、対象を指定します。全行には余白も含まれます。
  • 上部の「元に戻す」やCtrl＋Zで変更を取り消せます。やり直しはCtrl＋Shift＋Zです。

分岐を一括入力する場合も、最後に合計1へそろえてから解析します。入力エラーの一覧は、その場所へ移動するためのリンクになっています。

05 / READ RESULTS

結果はこの順番で読む

  1. 素辺ごとの現況と標準：V、規格化量j、臨界総流量、利用比を確認します。利用比1は臨界総流量と同じ、1より大きければその基準を超えています。
  2. 6方向の総量：どの方向で現況が標準より多い・少ないかを確認します。同方向の素辺の合計であり、道路網へ外から入った人数・台数そのものではありません。
  3. 三角形・六角形の回転：右回り、左回り、正味の違いを確認します。正味は右回りから左回りを引いた値です。
  4. 標準からの差：同じ面の標準値との比較なのか、標準状態の六角形群の平均との比較なのかを、項目名と説明で確認します。
  5. 計算の内訳：必要に応じてτや入力値の対応、配分調整の成否、未確定事項を確認します。
「差」は比較相手を一緒に読む。六角形の標準平均は、内側の完全な六角形について、右回り・左回り・正味をそれぞれ等重みで平均したものです。一つの面の標準値、前に保存した入力、一括比較の開始条件は別の比較相手です。

標準状態は各素辺に臨界量を置く比較基準です。元の観測入力や入口からの計算結果とは別に作られます。相互作用の仮計算・頂点分類は、表示される前提と合わせて読みます。相互作用スコアの大小を、そのまま先生のエネルギーや自動的な改善判定へ読み替えないでください。

「計算ログ」で処理内容を確認できます。入力を変更すると、表示していた結果は現在の入力に対する最新結果ではなくなります。変更後は再解析してください。

06 / BEFORE & AFTER

変更前後の比較を行う

練習例で、Vだけを1600から2000へ変えてみます。

  1. 練習例を読み込み、変更前の入力を確認します。
  2. 「現在の入力を変更前として固定」を押します。「変更前を固定：…」と表示されます。
  3. 素辺表の「複数の行へ一括入力」で、項目V、値2000、対象「全行（余白を含む）」を指定して適用します。
  4. 名前を「練習例・V=2000」に変え、「変更前と比較」を押します。
  5. 変更前・変更後の結果と差を確認し、比較結果のZIPを保存します。
確認する量変更前 V=1600変更後 V=2000変更後−変更前

この例はVだけを変えるので、標準状態の値は同じです。m・L・μや分岐割合などを変えた場合は、標準状態も変わり得ます。

版、格子、入力方法、規格化、回転の計算、θを変更すると、変更前の固定は解除されます。比較したい両条件の基本設定をそろえて、改めて固定してください。

07 / BATCH COMPARISON

一つの条件を、複数の値で比べる

「条件を振って一括比較」は、開始時の入力を固定して、指定した項目だけを各値に置き換えます。順番に変更を積み重ねる計算ではありません。

  1. 練習例を読み込みます。
  2. 「変更する項目」でm、「比較する値」に1, 2, 4、「変更する範囲」で「全体（余白を含む）」を選びます。
  3. 「条件を一括解析」を押します。
  4. 進捗が完了になったら、「比較グラフ・一覧を開く ↗」で結果を見ます。
  5. 必要に応じて「一覧CSV」と「一括比較をZIP保存 ↓」を保存します。

観測入力なので、mを変えてもV=1600は固定です。この設定ではτに入力側・出力側のmが現れるため、一様にmを変えると回転量は単純な1/mにはなりません。

指定使い方
値の数重複しない有限数を2〜12個。カンマで区切る
範囲全体、解析範囲内の素辺、選択した素辺のみ

「開始時の標準平均との差」は、開始時に計算した基準を固定した比較です。「各条件自身の標準平均」は、その条件で求め直した基準です。mを変える場合のように基準も変わるときは両方を確認します。

「残りの解析を中止」は、実行中の1件が終わった後、後続の計算を止めます。完了した条件と失敗した条件は一覧で区別します。途中で画面を再読込しても、一括比較の記録から進捗や結果を確認できます。

08 / ALLOCATION

入口・内部の配分調整を試す

入力方法を「入口の流入量から計算」にし、「配分調整と計算設定の説明」を開きます。最初は両方「調整しない」で計算し、基準となる結果を保存してください。

設定目的読むべき結果
方向別の標準総量に合わせる大局の方向別の総量を基準に、入口の受け入れを調整する調整後も各素辺の容量を満たすか確認
参考：容量と出口条件で最大流ネットワークの容量・出口を用いて受け入れを試算する受け入れ量と制約の結果
容量制約の下でτの変更を小さくする容量・保存則などの制約のもとで、現況からの変更を小さくする解消の成否、残った超過、変更した分岐

内部の配分調整は、現況のτからの変更を小さくする線形計画です。先生の相互作用エネルギーの最小化とは異なる処理です。方向別の合計に余裕があっても、局所の細い経路で容量を超えることがあります。

「未解消」や解なしが出た場合は、入口量・出口条件・容量を確認します。数値を変更する前に、結果に記録された理由を読み、調整前後を比較してください。

09 / SAVE & RECOVER

保存・作業復元・ケースの複製

「入力を保存」

その時点の入力を別の保存番号で残します。後から同じ条件を読み込むための操作です。解析時にも入力と結果が別の保存番号で残ります。

復元用の自動保存

編集中の入力・選択場所などを退避します。上部の「復元用に自動保存」と時刻を確認してください。明示的に保存したケースとは別に管理します。

  1. 「保存した入力・ファイルを使う」を開きます。
  2. 版、名前、保存日の範囲を指定して「絞り込む」を押します。日付は日本時間で、開始日・終了日を含みます。
  3. 「保存済みの入力」からケースを選び、「読み込む」を押します。解析結果が残っていれば一緒に表示します。
  4. 元のケースを残して変更したい場合は「複製して編集」を使い、名前を変えて保存します。

再読込や起動し直したときは、前回の退避データから入力や比較の基準を復元します。同じタブはそのタブの作業を優先し、複数タブの編集は分けて保持します。通常の共通起動と版を指定した起動では、復元候補の版が異なる場合があります。

保存済みデータと復元用データは、ツールのgui-work/に入ります。別PCへ持ち出すときは入力JSON・結果ZIPを保存するか、この保存フォルダも含めてコピーします。配布された新しいツールに過去の保存ケースが自動で含まれるわけではありません。

CSVを編集するとき

まず画面から書き出したCSVをテンプレートにしてください。列名・列の順序・場所を表す最初の4列を維持し、場所の行に欠落・重複を作らないようにします。文字コードはUTF-8を使います。

edges.csv
node_type,i,j,road,m,L,v,V,T,mu

branching.csv
node_type,i,j,in_road,S,R,L

entrances.csv
node_type,i,j,in_road,inflow

CSVだけでは格子サイズ・版・規格化の設定を持ち運べません。別PCや別の人に渡す場合は、設定を含むJSONを一緒に使ってください。

calculation_trace.json入力から中間項までの計算の対応
interactions.csv / spin_interaction_trace.json仮の相互作用計算で使用した面・値・式
compare.json変更前後の比較結果。個別結果はbase/・scenario/

通常の解析ZIPを展開すると、state.jsonを画面の入力JSONとして読み直せます。一括比較のZIPは、展開してsweep.htmlを開くとグラフと個別結果をオフラインで閲覧できます。

11 / REPRODUCE

同じ入力・当時の実装で再計算する

「計算の版と再現に必要な記録」には、ソフトと式の版、入力や実装の識別情報が残ります。再計算に必要な入力と実装は、結果に含まれます。

  1. 解析結果のZIPを保存し、別のフォルダへ展開します。
  2. 結果のprovenance.jsonで、ソフト・Python・依存ライブラリ・入力の識別情報を確認します。
  3. 結果内のengine_snapshot.zipをその結果フォルダへ展開します。当時のkagome_lattice/と環境情報が入っています。
  4. REPRODUCE.txtの手順に沿って、必要なPythonとライブラリを準備し、記載のコマンドを実行します。
  5. replay-input/から読み込んで作られたreplay-output/を、元の主要CSVと照合します。

特許版・交通版の表示用語や解析名は、入力の数値の識別とは分けています。同じ数値・計算設定なら、版の表示が異なっても同じ入力識別値になる場合があります。異なるOS・ライブラリでの完全なビット一致まで保証するものではありません。

12 / TROUBLESHOOTING

困ったときに確認すること

起動しない・初回準備が途中で止まった

ZIPを展開したか、Python 3.9以降が利用できるか、初回のネット接続があるかを確認します。表示されたコンソールのエラーを保存し、起動ファイルを再実行してください。ツールのフォルダは書き込み可能な場所で使います。

練習例と数値が違う

練習例を読み込み直し、観測入力、N=3、余白あり、m/engine、θ=0.5を確認します。一括入力は余白を含む全行へ適用してください。素片内のn=20を流量V=20として入力しないようにします。

入力エラーが出る

一覧の場所を押して、空欄、数値の符号、分岐の合計、θを直します。NaNや無限大は使えません。CSVでは列の順序と行の場所を確認します。標準比較にはμ・Tも必要です。

閉循環・一意な定常解がないと表示される

入口から計算する場合の分岐・出口の関係を確認します。閉じた経路から外へ出る割合が0だと、定常の計算が成立しない場合があります。入口と分岐の条件を見直してください。

「変更前と比較」が押せない

現在の入力を変更前として固定します。格子・版・入力方法・規格化・回転方式・θを変えた場合は固定が解除されるので、両条件で基本設定をそろえます。

自動保存に失敗と表示された

画面を閉じる前に「入力一式を書き出す」でJSONを保存します。起動コンソールが動いているか、保存フォルダに書き込めるかを確認してください。復元はバックアップの代わりにはならないため、重要な結果はZIPでも残します。

配分調整を行っても超過が残る

結果の調整の成否と理由を確認します。入口量、出口を維持する条件、各素辺の容量の組合せにより、指定条件を満たす流し方が存在しない場合があります。

「操作画面を開き直してください」と出る

サーバーの再起動などで操作画面の接続情報が変わった可能性があります。現在の起動コンソールに表示されたURLで操作画面を開き直します。

13 / CHECK BEFORE SHARING

結果を説明するときの確認項目

  • 特許版・交通版のどちらで読み、各入力が何を表すか説明できる。
  • 観測入力と入口からの計算を区別し、単位・格子範囲・余白の条件が分かる。
  • 現況、同じ面の標準、標準平均、変更前のどれと比較した値かが分かる。
  • 右回り・左回り・正味を区別し、仮の相互作用の前提を確認した。
  • 入力JSONと結果ZIPを保存し、計算の版を後から確認できる。

式の導出、記号の意味、標準状態の位置付け、先生の資料との対応は原理解説書で確認できます。
