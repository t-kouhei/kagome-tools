# 入口調整を確認する合成入力

先生の指定例や実データではありません。現在の汎用モデルで、方向別の標準総量に基づく入口調整を確かめます。

JSONを保存し、「保存した入力・ファイルを使う」内の「入力JSONを読み込む」から開いて解析します。必要な編集中の入力は先に保存してください。

全例でN=3・余白あり、m=2、L=0.5、v=40、μ=1000、T=100、θ=0.5、直進100%です。入力方法は入口からの計算、入口調整はdirection、内部調整はなし。各素辺の容量は2000です。

| ファイル | 要求合計 | 受入合計 | 未受入合計 |
|---|---:|---:|---:|
| low.json | 38000 | 38000 | 0 |
| high.json | 228000 | 76000 | 152000 |
| direction-6-off.json | 174000 | 58000 | 116000 |

向き1は5入口・45区間です。high.jsonの外部要求は30000、受入は10000。一方、内部の区間合計は270000→90000、標準総量は90000です。

direction-6-off.jsonでは、向き6の9入口だけ要求量0とします。経路や標準容量を削除する指定ではありません。この直進だけの例では内部の向き6も0、標準総量は82000のままです。

詳細は仕様書の第4.3・7.3・7.4節を参照。公開版：<https://t-kouhei.github.io/kagome-tools/specification.html#admission>
