02 / GEOMETRY

格子・素辺・分岐の定義

三角形と六角形が並ぶカゴメ格子の交点を、種類C・D・Eと整数添字(i,j)で識別します。素辺には向きがあり、同じ区間の往路と復路は別の入力です。方向番号は水平右向きを1として、60度ずつ反時計回りに1～6を割り当てます。反対方向は(1,4)、(2,5)、(3,6)です。

記号意味変えると何が変わるか
N解析する単位格子の縦横の数格子の節点数・素辺数
halo（余白）周囲に1リング追加する補助領域端の局所計算に使う隣接値の範囲
m一つの素辺にまとめた並列経路数規格化とτ・臨界総流量。格子の接続そのものは増えない
L素辺の実際の長さnからVへの換算、τの長さ比。画面上の線の長さとは独立

分岐割合は「節点」「入ってくる方向」の組ごとに指定します。直進・右回り側・左回り側をそれぞれβS・βR・βLと書きます。

βS ≥ 0,　βR ≥ 0,　βL ≥ 0
βS + βR + βL = 1入力は割合。例えば60%は0.60。R/Lは当該の流入方向から見た進行方向。

余白を含む全域をall、解析対象の内側をinnerと表します。内側の素辺は両端が内側にある有向素辺です。余白に入れる値も計算に使うため、根拠のある入力が必要です。余白を付けても、入口から伝播した流量が境界条件と無関係になるわけではありません。

04 / FLOW

観測した流量を読む／入口から流量を求める

観測モード

全ての素辺のVを直接入れ、入力された状態を分解・診断します。節点で流入と流出が大きく違う場合は警告し、その入力が表す状態を確認できるようにします。観測値を入口から説明する逆推定では、非負最小二乗と残差を使います。残差が小さいことと、入口を一意に識別できることは別です。

入口から計算するモード

格子の入口流量qと分岐割合から、各素辺の定常流量を求めます。Mは、ある素辺の流れが次の素辺へ渡る割合を並べた行列です。

V = M V + q
(I − M) V = q式としてはV=(I−M)−1q。実装は連立方程式を解き、残差と流量の妥当性を確認する。

正の分岐をたどって各素辺から出口へ到達でき、分岐が非負で保存的な場合を扱います。流れが出口のない循環へ入り続けると有限な定常状態になりません。流入がない閉循環でも、その中の循環量は入口条件だけでは一意に決まりません。ツールはこうした入力を診断して計算を止めます。

2つのモードで比べているもの

観測モードは「与えた各素辺の流量」、入口モードは「入口と分岐から導かれる定常流量」です。条件比較ではモードと境界条件をそろえて、変更したパラメータの影響を読みます。

06 / REFERENCE STATE

臨界量を求め、比較基準を作る

実装の式 規格化量εが臨界基準μを超えるほど大きくなる、次の増加型の分布スコアを使います。通常はε=jです。

f(ε;μ,T)=11+exp(μ−εT)ε*=μ+Tln(θ1−θ)c=mε*f=θになるε*が臨界規格化量、cは総流量の単位へ戻した臨界量。θ=0.5ならε*=μ、c=mμ。

この符号ではεが増えるとfも増えます。fは現在のモデルが定義する分布スコアであり、実測で校正した「渋滞する確率」ではありません。Tは曲線の幅を変え、θ=0.5のときの臨界点μ自体は変えません。

コードのfermi_diracという名前だけから、別の分野で使う減少型の占有分布を代入しないでください。実装と比較する際は上の符号を使います。CLIで--eps straightを選ぶと分布と比較する量は直進成分になりますが、臨界総流量cの定義は同じ規格化の逆変換に基づきます。解釈が変わるため、結果の設定を明記します。

jstandard,e = Vstandard,e/me
(τ, s, σ)standard = 同じ分岐・長さ・本数で標準流量を分解

全ての素辺を臨界点に置く案は、先生の会議で示された比較基準に対応します。現況の素辺ごとの流量差はV−c、比はV/cです。

比較基準と、保存則を満たす流れ

各素辺のcを独立に並べた状態が、各節点の流入・流出や分岐と整合するとは限りません。現在の標準状態は比較基準として計算します。可解格子の調和状態・基底状態との一致を主張するためには、追加条件と対応する計算規則の確定が必要です。

07 / COMPARISON

6方向の総量、素辺、回転量を比較する

方向別の比較

Qd = Σ方向dの対象素辺e Ve　　Cd = Σ同じ対象素辺e ce
ΔQd = Qd − Cd

内側だけのinnerと余白込みのallを出し、現況と標準を同じ素辺集合で足します。同じ対象が直列の2区間を通る場合、両方の区間の流量として数えます。従って、この合計は対象範囲全体への入口流入量や、ネットワークが受け入れられる最大流とは異なる集計量です。

例えば標準が[20,30]、現況が[25,15]なら方向合計は40−50=−10です。しかし最初の素辺は5超過しています。方向の合計だけで局所の超過を判断せず、超過本数と相殺しない超過量も見ます。

面の標準値と、標準平均を区別する

個別の差：σ+now,h − σ+standard,h
標準平均：μ̄+H = (1/|H|) Σh∈H σ+standard,h

平均の対象Hは、全6頂点が解析範囲内にある完全な六角形です。現在は等重みで平均します。対象となる六角形がない場合、平均と比較値は出ません。面ごとの標準値が異なる非一様入力では、個別の差と平均との差も異なります。

基本表示は右・左・正味の回転量と、同じ面の標準との差、解析範囲内の完全な六角形の標準平均との差です。個別標準が10・20、現況が12・18なら個別差は＋2・−2、標準平均15との差は−3・＋3。どちらも別の比較として表示します。

正味Sの積は任意に参照する仮の指標です。標準(10,10)と現況(20,5)の積は共に100でも、各面の回転量は変わっています。積の大小を改善や調和の判定には使いません。標準の|S|平均が0、または対象面がないときは積を算定保留にし、JSONではnull、CSVでは空欄、画面では「–」と理由を表示します。代わりに規格化係数1を置きません。

現行の分布f=1/(1+exp((μ−ε)/T))は増加型で、基本はε=J、基準で0.5です。原資料の減少型は1−fに対応し、しきい値も1−θと対応させます。良否の意味は用途側で定めます。CLIで直進成分を評価する場合も、容量・標準状態はJに基づくため、標準の直進分布値がθになるとは限らない旨を表示します。

容量として使うε*=μ+T ln(θ/(1−θ))とcは正の有限数に限定し、0以下になる入力は解析前に停止します。分布単独のAPIは数学的な値を返せますが、非負量の範囲に正の基準がない場合はthreshold_statusで示し、比はnullです。m・L・v・μ・Tは正、Vは非負、分岐割合は非負で合計1が基本の入力条件です。

基準は比較用の参照状態で、実現可能な平衡流や厳密解の証明とは別に扱います。6方向の合計は区間ごとの加算であり、直列区間を通る同じ流れも各区間で数えます。入口の受入量・最大流と区別します。三角形・六角形の基本の回転式と接続は変更していません。
